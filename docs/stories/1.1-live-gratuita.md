# Story 1.1 — Página gratuita MargeX

Status: Ready
Origem: requisitos e decisões explícitas do usuário nesta conversa, 2026-11-12. Blueprint sujeito a validação de aderência antes da implementação.

## Resultado
Como seller que percebe prejuízo no Mercado Livre, quero entender a proposta da live e percorrer um formulário de inscrição, para avaliar como analisar minha operação.

## Critérios de aceitação
- [x] Identidade do manual aplicada; hero com professor e animação de catálogo.
- [x] Sem o rótulo 'simulação ilustrativa', conforme correção do usuário; sem resultados ou garantias inventados.
- [x] Estrutura aprovada e versão curta preservada para comparação.
- [x] CTAs abrem formulário de uma pergunta por vez; página direta reutiliza o fluxo.
- [ ] Formulário valida campos, permite voltar e funciona por teclado e celular.
- [x] Sem envio ou sucesso falso: planilha, grupo e qualificação identificados como pendentes.
- [x] Materiais, programa e cases ausentes preservados como pendentes, sem fabricação.
- [x] Sem publicação, coleta real, secrets ou mudanças em framework protegido.
- [ ] Verificação de sintaxe, HTTP e QA desktop/mobile executados.

## Dev Agent Record
Implementação vanilla sem dependências, baseada no blueprint validado. Timeline de oito segundos com pausa/repetição e estado final estático para movimento reduzido; duas extensões da narrativa por query. Formulário compartilhado em dialog e página direta, campos provisórios, validação e rascunho apenas em memória. Integrações não implementadas: conclusão explicitamente de prévia. Servidor de desenvolvimento limitado a loopback, GET/HEAD e allowlist de arquivos públicos. Não inicializado git, não publicado. QA visual e HTTP sob responsabilidade do root.
